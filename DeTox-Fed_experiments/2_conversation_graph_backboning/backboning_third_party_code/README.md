# Third-party code for backboning

`backboning.py` is the network backboning library by Michele Coscia, accompanying

> M. Coscia and F. M. H. Neffke, "Network Backboning with Noisy Data," *IEEE 33rd International Conference on Data Engineering (ICDE)*, 2017.

Original source: <https://www.michelecoscia.com/?page_id=287>. It is included unmodified and is used by `../noise_corrected_backboning.ipynb`.
